# Единый продукт из всех Telegram-ботов (Gorilla + Gonka + LifeKey)

## Цель
Собрать все боты в один продукт, не удаляя ни одной функции: память, автопостинг, ассистенты, крипто-режим и т.д.

## Что есть сейчас
- `Gorilla_bot/bot.py`: ассистент + память пользователя + автопостинг + AI-постинг.
- `gonkaai/bot.py`: крипто-ассистент + BTC/ETH + автопосты.
- `lifekey`: в текущем дереве репозитория не найден как отдельная папка/модуль, но архитектура ниже уже готова к его подключению.

## Как упаковать в один продукт

### 1) Единая точка запуска (одно окно)
- Добавить `run_all_bots.py`, который запускает все боты в одном терминальном окне как отдельные процессы.
- Каждый процесс пишет лог с префиксом (`[gorilla]`, `[gonkaai]`, `[lifekey]`).
- Если `lifekey` отсутствует в репозитории, процесс просто пропускается и выводится понятный warning.

### 2) Единый конфиг
- Общий `.env` в корне:
  - `RUN_GORILLA=1`
  - `RUN_GONKAAI=1`
  - `RUN_LIFEKEY=1`
  - `LIFEKEY_ENTRY=lifekey/bot.py`
- У каждого бота свои переменные остаются, но управление запуском централизуется.

### 3) Единый наблюдательный контур
- Общий формат логов (дата, модуль, уровень, сообщение).
- Единый канал для алертов (ошибки автопоста, недоступность API, rate limit).

## Фишки для продукта
1. **Router-бот (meta entrypoint)**
   - Один публичный бот-коммутатор, который по командам направляет пользователя в нужный сценарий:
     - `/coach` → Gorilla
     - `/crypto` → Gonka
     - `/lifekey` → LifeKey

2. **Кросс-бот профиль пользователя**
   - Единый профиль и теги интересов (фитнес/крипто/психология), чтобы рекомендации в разных ботах были согласованы.

3. **Панель контента**
   - Команда `/post_preview` и `/post_send` для ручного утверждения автопостов перед отправкой.

4. **A/B шаблоны постов**
   - Несколько стилей для каждого канала (агрессивный, аналитический, короткий), метрика CTR/реакций.

## Улучшение постов (чтобы не были примитивными)
- Структура поста: заголовок + блок ключевых цифр + сигнал/контекст + действие + хештеги.
- Визуальный ритм: эмодзи-маркеры, разделители, короткие блоки.
- Динамические элементы: сигнал рынка, уровень уверенности, “идея дня”, вопрос для вовлечения.
- Анти-дублирование: проверка на повтор шаблона/формулировки в последних N постах.

## Пошаговый план внедрения (без поломки текущих функций)
1. Добавить `run_all_bots.py` и запускать текущих ботов как есть.
2. Вынести секреты в `.env` и добавить проверку обязательных переменных.
3. Добавить общий logger + алерты.
4. Подключить LifeKey через `LIFEKEY_ENTRY`.
5. Ввести A/B шаблоны постов и анти-дублирование.
